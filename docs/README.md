1. Tool Calling
2. Single-Agent Orchestration
3. Multi-Agent Delegation
4. RAG / Grounded Generation
5. Observability
6. Human-in-the-Loop
7. Guardrails
8. Agent Evaluation

Agent memory is planned future work and is therefore intentionally not included in the implemented learning path.
